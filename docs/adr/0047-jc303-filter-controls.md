# ADR 0047: JC-303の音色パラメーターをメイン画面で操作する

- 状態: 採用
- 決定者: user（Surge XTのMacro欄と同様に横棒とsweepで操作すること、対象の8項目と表示上の `Filt.`・`OD`）

JC-303のフィルターを試聴中に調整するには、都度Show UIで音源の画面を開く必要があった。一方、Surge XTではMacro欄から演奏を聴きながら値を変えられたため、JC-303のフィルターにも同じ操作を割り当てる。

## 決定

CLAP `co.midilab.JC303` は `Cutoff` と `Resonance` を、音色内の割り当てに依存せずオートメーション可能なパラメーターとして公開している。確認した実機の値域はいずれも0〜1。公開名で対象を特定し、0〜127の横棒をホストが取得した値域へ写す。MIDI learnの有無に左右されないよう、[既存のパラメーター送信](0037-direct-parameter-automation.md)を使う。

最初の2枠にCutoffとResonanceを割り当てた。フィルター以外も試聴中に調整したいというuserの要望を受け、実機のパラメーター一覧からuserが選んだ `Filt. EnvMod`、`Filt. Decay`、`Accent`、`Waveform`、`OD Drive`、`OD Dry/Wet` を残りの6枠に割り当てる。これらも同じ方法で送信でき、ODの2項目はオーバードライブが有効な音色で効く。

個別操作、別々のsweep周期、一括切り替え、アプリ内で音色を変更したときの固定値解除は[既存のMacro欄](0036-surge-xt-macro-sweep.md)と共通にする。8項目の値は音色を直接決めるため、Favorite比較にも含める。

起動時に操作を復元する場合は、初めの音にもその値を反映する。すべて `-` で起動時に復元した場合は、まず通常どおり発音し、初回の操作でオートメーションを準備する。準備は音声処理を停止して行う必要があるため、この場合は初回だけ再生経路を組み直す。アプリ上で音源を選んだ場合は選択時に準備し、操作中は同じ再生経路を使う。
