# ADR 0041: FluidSynthPluginの非標準カテゴリ区切りに限定対応する

- 状態: 採用
- 決定者: user（YAGNIを優先し、slashだけを追加で認識すること）

## 目的と判断

プラグイン一覧では、公開されたカテゴリを使ってinstrument・effect・不明を分け、楽器を見つけやすくしている。
VST3のカテゴリは標準の `|` 区切りを前提としていたが、userからFluidSynthPluginが楽器の並ぶ位置に見当たらないとの報告があった。
実際にはスキャン済みで、不明として一覧の下方に並んでいた。

実機のFluidSynthPlugin（公開バージョン1.0.0）は `Instrument/Synth` を返し、DLLの読み込みとホスト経由の生成は成功した。
[公式SDK](https://github.com/steinbergmedia/vst3_pluginterfaces/blob/master/vst/ivstaudioprocessor.h)の定義は `Instrument|Synth` であり、
プラグインが非標準の区切りを使うため、標準表記だけを受け入れる種類判定では楽器と認識できなかった。

FluidSynthPluginへのアドホックな互換対応として、VST3の種類判定は `|` に加えて `/` も区切りとして受け入れる。
プラグイン名やIDによる例外は設けず、分割した項目の `Instrument`・`Fx` との完全一致と、両方ある場合は不明とする判断を保つ。

## 見送ったものと制限

任意の1文字や英数字以外の文字を区切りにする案は、実例のない表記まで受け入れるため、userのYAGNI判断で見送った。
`/` 以外の非標準区切りは追加しない。これはカテゴリの互換対応であり、FluidSynthPluginの発音や全機能の互換性を保証する判断ではない。
依存ライブラリやインストール済みプラグインは変更しない。

保存形式は変えず、既存の不明という分類は通常の再検出で更新する。
プラグイン側が標準表記へ修正された場合は、同じ非標準表記を使う実利用プラグインの有無を確認してから、この互換対応の撤去を判断する。
